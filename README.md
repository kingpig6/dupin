# 獨品工坊開單系統

客製重機彩繪訂單管理 PWA，連接 Google 試算表。

## 快速啟動（5 步驟）

### 步驟 1：確認試算表工作表欄位

確認你的試算表有以下 4 個工作表，並在第 1 列填好欄位標題：

**訂單**
```
訂單編號 | 客戶 | 開單日期 | 交貨期限 | 狀態 | 收款狀態 | 備註
```
> ⚠️ 你現有的表缺「收款狀態」欄，請在 F 欄標題補上「收款狀態」，G 欄改成「備註」。

**客戶**
```
客戶名稱 | 聯絡人 | 電話 | 統一編號 | 地址 | 備註
```

**品項**
```
品項ID | 訂單編號 | 品名 | 規格 | 數量 | 單價 | 金額 | 車號 | 負責師傅
```

**設定**（第 A 欄=鍵，第 B 欄=值，逐列填入）
```
廠商名稱  | 獨品工坊
負責人    | 李安晟
統一編號  | 95323326
電話      | 0919726434
LINE      | kingpig6
匯款銀行  | 玉山銀行 808 台中分行
匯款戶名  | 獨品工坊 李安晟
匯款帳號  | 1366940043038
稅率      | 0
```

---

### 步驟 2：部署 Apps Script

1. 開啟你的 Google 試算表
2. 上方選單 → **擴充功能** → **Apps Script**
3. 把 `Code.gs` 的內容全部貼上（取代原本的 `function myFunction()`）
4. 點「存檔」（Ctrl+S）
5. 點「部署」→「**新增部署**」
   - 類型：**Web 應用程式**
   - 執行身分：**我（your@gmail.com）**
   - 誰可以存取：**所有人（Anyone）**
6. 點「部署」→ 複製**部署網址**（長得像 `https://script.google.com/macros/s/AKfycb.../exec`）

> 之後修改 Code.gs 需要重新部署（「管理部署」→ 鉛筆編輯 → 版本選「新版本」）

---

### 步驟 3：填入 API 網址

開啟 `app.js`，找到第 5 行：
```js
const API_URL = 'YOUR_APPS_SCRIPT_URL_HERE';
```
把 `YOUR_APPS_SCRIPT_URL_HERE` 換成你剛才複製的部署網址。

---

### 步驟 4：部署網頁（GitHub Pages）

1. 把這個 repo 推到你的 GitHub
2. GitHub → Settings → Pages → Source 選 `main` 分支 `/ (root)`
3. 儲存後幾分鐘網址就可以用，例如：`https://yourname.github.io/dupin/`

---

### 步驟 5：手機加到主畫面（PWA）

- **Android（Chrome）**：開啟網址 → 右上角三點選單 → 「新增至主畫面」
- **iOS（Safari）**：開啟網址 → 下方分享按鈕 → 「加入主畫面」

## 功能說明

| 頁面 | 功能 |
|---|---|
| 訂單列表 | 依狀態分區（進行中 / 已完工待交貨 / 已交貨待請款 / 已開請款單 / 已收款），顯示客戶、金額、收款狀態 |
| 訂單詳細 | 查看品項、即時更改狀態、新增品項、產生請款單 |
| 開單 | 建立新訂單，自動產生訂單編號 |
| 客戶管理 | 新增/編輯/刪除常用客戶 |
| 業績統計 | 各客戶累計 + 自訂日期範圍查詢 |
| 請款單 | 一鍵預覽並列印/匯出 PDF（含民國年、品項表、廠商資訊） |

## 年度營收圖表（損益報告）

損益報告最上方有一張「${年} 年度營收與淨利」圖：

- **柱狀＝每月營收**（完工項目金額 ＋ 接單返還，與報表的「收入＋接單返還」同一個定義）
- **折線＝每月淨利**（營收 − 已支付傭金/抽成 − 公司支出，與報表的「淨利（已結算）」同一個公式）
- **淡灰線＝去年同月營收**，展開損益報告時自動補撈去年資料（只撈一次）
- 固定顯示今年，**不受上方日期篩選影響**；只畫到本月，未來月份不畫
- 每個月份都可以 hover／鍵盤聚焦看明細，另附「表格檢視」

實作說明：

- 純 inline SVG，**沒有引入任何圖表函式庫**
- 單一 Y 軸（營收與淨利都是金額，共用刻度）——刻意不做雙 Y 軸
- 配色經過色盲與對比驗證（深色底 `#1f2937`）：營收 `#c98500`、淨利 `#3987e5`。
  App 主色 `#f59e0b` 亮度超出深色底的容許範圍，只留給文字用
- 圖表 12 個月加總 = 損益報告整年的數字（有測試把兩者對過）

## 交貨追蹤

「**進度**」是工坊做完沒（待施工／施工中／完成），「**交貨狀態**」是東西交到客戶手上沒（未交貨／已交貨），兩者各自獨立：

- 訂單列表分五區：**進行中 → 已完工待交貨 → 已交貨待請款 → 已開請款單（未收款）→ 已收款**
- 進度改「完成」自動填**完工日期**；交貨狀態改「已交貨」自動填**交貨日期**（改回未交貨會清掉）
- 「已完工待交貨」區底部有「🚚 批量標記已交貨」，整批出貨時一次處理
- **開請款單移到「已交貨待請款」區**，也就是交貨後才開單
- 交貨只有**老闆（admin）**能標記，員工只看得到狀態；後端也會擋掉非 admin 送來的交貨欄位
- 抽成／傭金／月結報表仍以**完工日期**為基準，不受交貨影響
- 客戶查詢連結同步分成三段（進行中／已完工待交貨／已交貨待收款）並顯示交貨日

### 首次啟用（兩件事）

1. 「**工作項目**」工作表會在第一次寫入時自動補上「**交貨狀態**」「**交貨日期**」兩欄（也可以自己先加在最後兩欄）
2. Apps Script 介面選 **`backfillDelivery`** 執行一次，補既有資料：已開請款單或已收款者標為「已交貨」（交貨日期沿用完工日期），其餘標為「未交貨」。已標記過的列不會被覆蓋，重複執行安全

## 效能設計

系統的瓶頸不是 Google 試算表本身，而是**每次呼叫 Apps Script 的固定成本**（POST 會先 302 轉址到 googleusercontent，兩趟來回加上容器啟動，約 1～3 秒）。因此設計上的原則是**盡量少打幾次**：

| 動作 | 後端請求數 |
|---|---|
| 改進度／收款／交貨 | 1 次 |
| 批量收款／交貨 40 件 | 1 次（每 50 件一批） |
| 結算某位師傅 | 1 次 |

做法：

- **`updateBatch`**：一次請求改多列，一次拿鎖、一次讀表，相鄰的列合併成同一個 `setValues` 寫回
- **寫入後只重畫、不重載**：前端已樂觀更新，`rerender()` 不觸發 `getBundle`
- **身分驗證走快取**：`getUserRole` 改用 `readSheetCached`（副作用：在試算表改員工角色最多 30 秒生效，要立即生效就執行一次 `invalidateCache('員工')`）
- **批量操作顯示進度**：畫面上出現「已完成 N / M」進度條

### 軟歸檔（資料不搬移）

工作項目會越積越多，但**資料完全不搬走**，全部留在同一張「工作項目」表。只是 `getBundle` 預設只送：

- **所有未結案**（收款狀態 ≠ 已收款）
- **所有未付的費用**（費用支付狀態 = 未支付）
- 加上**最近 `ITEM_WINDOW_MONTHS` 個月**（預設 12）有日期的項目

要查更早的，前端才呼叫 `getItemsRange(from, to)` 補撈，合併進 `statsItems()` 給統計用。

- 業績、損益、傭金報表選到較早的日期時**會自動補撈**，數字與全量載入完全相同
- 訂單列表「已收款」區塊底部有「**載入更早的紀錄**」按鈕
- 想恢復成全部送出，把 `Code.gs` 的 `ITEM_WINDOW_MONTHS` 設成 `0` 即可，不需要改其他地方

> ⚠️ `readSheetCached` 的快取上限是 100KB，約 350～400 列。超過之後快取會安靜失效（不報錯，只是變慢）。屆時可考慮縮減 `getBundle` 送出的欄位。

## 員工權限設定

系統支援 **老闆（admin）／員工（staff）** 兩種角色，需先設定 Google 登入：

1. 在 Google Cloud Console 建立 OAuth 用戶端 ID，貼到 `app.js` 的 `GOOGLE_CLIENT_ID`
2. Apps Script →「指令碼屬性」新增 `GOOGLE_CLIENT_ID`（值需與上面相同）
3. 試算表建立「**員工**」工作表，欄位：
   ```
   email | 姓名 | 角色 | 抽成比例
   ```
   - `角色` 填 `admin`（老闆，完整權限）或 `staff`（一般員工）
   - `抽成比例` 選填，僅「抽成」類型的傭金計算會用到（例如 0.1 代表 10%）
4. 「**工作項目**」工作表建議加上「**建立者**」欄位（放在最後一欄即可），系統會自動填入開單者的姓名/email，供事後查核是誰開的單

登入後，**員工帳號**只能看到：
- 「進行中」裡「負責師傅」欄位空白（尚未指派）的項目，且**唯讀**（無法修改進度、收款狀態，也不能編輯或刪除）
- 「業績」分頁會換成「我的傭金」：自己「完工尚未結款」與「已結款」的傭金/抽成，已結款可用「本月」按鈕或自訂日期區間查詢
- 可以正常使用「開單」建立新工作項目（會記錄自己是開單人）

**老闆帳號**維持完整權限（所有訂單、業績統計、損益報告、刪除、開請款單等）。
